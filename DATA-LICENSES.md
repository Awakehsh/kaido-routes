## Bundled whole-Shuto database

`shuto-whole-network-20260804.json` is a machine-readable derivative database
built from OpenStreetMap data.

- Attribution: © OpenStreetMap contributors
- OpenStreetMap copyright and attribution information:
  <https://www.openstreetmap.org/copyright>
- Database license: Open Data Commons Open Database License (ODbL) 1.0
  (`ODbL-1.0`)
- License URI: <https://opendatacommons.org/licenses/odbl/1-0/>
- Source snapshot:
  <https://download.geofabrik.de/asia/japan/kanto-260804.osm.pbf>
- Reconstruction instructions:
  <https://github.com/Awakehsh/kaido-routes/blob/main/data/route-atlas/osm-derived/shuto-whole-network-20260804.README.md>

The derivative database itself is included in this application bundle as
`shuto-whole-network-20260804.json` and is made available under ODbL 1.0. The
repository's Apache-2.0 license applies to project code and does not relicense
this database.

## Bundled place photographs

square thumbnails of Wikimedia Commons photographs. They are bundled only
as map identifiers. Apache-2.0 does not relicense these images; each file
keeps its source licence. Cropping and resizing are adaptations of the
originals.
